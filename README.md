# Calculate the Final Distance Between Two Points

## Description
This program calculates the distance between two points on a coordinate plane, (x1, y1) and (x2, y2), using the distance formula. It asks the user to enter the coordinates and then displays the distance between them.

## How to Run
1. Open the project folder in Visual Studio Code.
2. Make sure Python extension is installed in VS Code.
3. Open the file and run the code cell (click play Run button next to it).
4. Enter the requested coordinate values when prompted.

## Input Needed
- x1: the x-coordinate of the first point
- y1: the y-coordinate of the first point
- x2: the x-coordinate of the second point
- y2: the y-coordinate of the second point

## Sample Output
Enter x1: 6

Enter y1: 7

Enter x2: 6

Enter y2: 7

The distance between the two points is: 0.0
